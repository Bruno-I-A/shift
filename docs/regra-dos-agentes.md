# Shift CRM — o quadro dos projetos

Vale quando o MCP `shift-crm` estiver conectado. É o quadro onde o Bruno
acompanha os projetos de cliente; ele só fica certo se os agentes o alimentam.

**Ao começar a trabalhar num repositório:** chame `projeto_atual` com a saída de
`git remote get-url origin`. Leia a etapa, as tarefas abertas e as últimas
sessões antes de planejar. Se vier `nota_cerebro`, abra essa nota no Cerebro.

**Durante:** pendência concreta que vai ficar para depois vira `criar_tarefa`.
Tarefa que você terminou, `concluir_tarefa`.

**Ao terminar trabalho que mudou algo:** `registrar_sessao` com o que foi feito
e o que falta, em português, como você contaria ao Bruno.

**Etapa:** você não muda, propõe (`propor_etapa`) com o motivo, e só quando o
projeto mudou de fase de fato — não a cada sessão. O Bruno aprova na tela Hoje.

**Repositório fora do CRM:** não crie nada. Pergunte ao Bruno qual é o projeto.

CRM guarda status; o Cerebro guarda conhecimento. Aprendizado vai para o vault,
não para o resumo da sessão.
